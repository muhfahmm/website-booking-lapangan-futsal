Buatkan struktur halaman Admin Panel menggunakan PHP dan Tailwind CSS. 
Ketentuan:
1. Layout: Sidebar di sebelah kiri (bg-slate-900, text-white, width-64, fixed) dan Main Content di sebelah kanan.
2. Komponen Sidebar: Menu Dashboard, Kelola Lapangan, Kelola Booking, Kelola Konten, dan Logout.
3. Tampilan: Gunakan font Sans-serif, berikan shadow pada header dashboard, dan gunakan card style (bg-white, shadow-md, rounded-lg) untuk isi konten.
4. Fitur: Gunakan tabel dengan style zebra-striping (bg-gray-50) untuk menampilkan data dari database (tb_lapangan, tb_booking, dll).
5. Interaksi: Tambahkan hover effect pada setiap item menu di sidebar dengan background emerald-700.
6. Responsive: Pastikan layout aman diakses via tablet/desktop.
7. Kode: Tulis kode PHP yang bersih dengan pemisahan logic (koneksi database di include dari file terpisah) dan struktur HTML yang modular.
