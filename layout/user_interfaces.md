Buatkan landing page untuk website booking lapangan futsal menggunakan PHP dan Tailwind CSS.
Ketentuan:
1. Header/Navbar: Sticky, transparan saat top, berubah menjadi bg-emerald-700 saat scroll. Navigasi: Home, Lapangan, Booking, Kontak.
2. Hero Section: Full-height, background gambar lapangan futsal dengan overlay gelap (bg-black/50), teks utama "Booking Lapangan Futsal Tanpa Ribet", dan tombol CTA "Booking Sekarang" (bg-yellow-400, text-slate-900, font-bold).
3. Section Lapangan: Tampilkan grid card berisi daftar lapangan (nama, harga, status). Gunakan style card: border-l-4 border-emerald-600.
4. Section Footer: Simple dark footer (bg-slate-900) dengan link sosial media.
5. Estetika: Gunakan palet warna utama Emerald (Hijau) dan aksen Kuning (Yellow) sesuai desain modern.
6. Responsivitas: Gunakan grid-cols-1 untuk mobile dan grid-cols-3 untuk desktop agar tampilan rapi.
7. Backend Integration: Pastikan bagian konten diambil dari database (tb_konten) agar bisa dikelola via admin panel.
